# DataClaw 产品需求文档（PRD）

## 1. 产品概述

DataClaw 是运行于用户本机的公开信息采集工作台。它帮助运营人员持续整理公开资讯，并将其转为可发布内容。第一期以海关总署公开资讯为样例，后续可通过代码接入更多固定采集源。

产品不以绕过网站保护为目标。它只处理无需登录的公开网页，并通过节流、轮转、重试和可停止任务降低对目标站点的访问压力。

## 2. 目标与非目标

### 目标

- 从本地界面发起单项或多路由采集。
- 仅采集增量文章，保留来源、路由和原文网址。
- 将正文转换为清晰的段落文本，并生成前端可用的 HTML。
- 展示采集状态、历史日志、失败原因和可控的执行参数。
- 采集任务可随时停止，新任务不受历史失败状态影响。

### 非目标

- 不绕过验证码、登录、付费墙、访问限制或反自动化验证。
- 不提供云端托管、多人协作、账号体系或远程公开访问。
- 当前不提供用户在界面中新增或删除采集源；采集源由代码内置管理。
- 当前不提供定时调度；采集由用户手动触发。

## 3. 用户场景

| 场景 | 用户动作 | 产品结果 |
| --- | --- | --- |
| 每日采集多个栏目 | 选择路由并一键采集 | 按策略抓取增量文章并记录日志 |
| 只关注一个栏目 | 点击该路由的采集按钮 | 仅处理该栏目，继承正文间隔和重试设置 |
| 网站临时限流 | 查看状态或停止任务 | 冷却后重试，或立即停止且保留已入库内容 |

## 4. 功能需求

### 4.1 采集中心

- 展示采集网站、采集路由、是否直接推送、上次采集时间、采集状态。
- 每条路由支持单项采集。
- 支持选择多个路由、全选路由和一键采集。
- 运行时展示“排队中”“采集中”“完成”“部分失败”“采集失败”“已停止”等状态。
- 任务运行时显示停止入口；停止后立即结束等待与当前浏览器会话。
- 历史失败只保留在工作日志中，不阻止下一轮任务。

### 4.2 采集设置

独立页面地址为 `/#settings`，支持保存以下参数：

| 参数 | 含义 |
| --- | --- |
| 执行方式 | 轮转采集或逐栏目采集 |
| 列表页间隔 | 多栏目场景下，访问相邻列表页之间的等待时间 |
| 正文最小/最大间隔 | 每篇正文之间的随机等待区间 |
| 每轮冷却 | 一轮多栏目正文抓取后休息的时间 |
| 首次/第二次重试等待 | 收到临时 HTTP 400 后，重建会话前的冷却时间；412 验证页会进入人工验证流程 |
| 最大重试次数 | 单页面因临时限制可重试的次数 |
| 单路由文章上限 | 单次任务每条路由最多处理的候选文章数量 |

默认推荐“轮转采集”：先读取各选中栏目的列表页，再按照“每个栏目各处理一篇”的顺序轮转，降低对单一栏目的连续访问。

单项采集继承正文间隔、重试等待、最大重试次数和文章上限；由于只有一个栏目，不使用栏目间列表页间隔和多栏目轮次冷却。

### 4.3 内容与日志

- 从栏目页提取文章链接，并以原文 URL 与最终跳转 URL 去重。
- 提取标题、正文、发布时间（如可识别）、来源名称、来源路由和原文 URL。
- 正文以空行分段保存；无法识别可靠正文的页面不会入库。
- 每篇入库文章生成 HTML 与 JSON 导出文件。
- 内容库支持编辑、HTML 导出和删除；删除同时清理对应导出文件。
- 工作日志按采集源、开始/结束时间、新增数、跳过数、失败数和最终状态记录。
- 遇到站点 JavaScript 验证时，路由显示“需要验证”与原因，并提供“打开验证页面”；用户完成网站要求的公开验证后可重新采集。

## 5. 关键流程

### 一键采集（轮转模式）

1. 用户选择路由并点击一键采集。
2. 系统创建新的本次任务状态，历史失败仅保留在日志中。
3. 系统按列表页间隔读取各路由栏目页，建立新增候选队列。
4. 每轮从每条路由各取一篇正文，按正文随机间隔依次处理。
5. 每轮完成后按设置冷却，直到候选完成或用户停止。
6. 更新每条路由状态和工作日志。

### 限流与停止

- 遇到 HTTP 400 时，按设置冷却、关闭旧 Chrome 会话后重试。
- 遇到 HTTP 412 的网站验证页时，保留采集专用浏览器档案并明确提示人工完成网站验证；系统不会尝试绕过验证。
- 重试耗尽后记录失败原因，不影响其他路由继续执行。
- 用户停止任务时，立即取消等待、关闭 Chrome，并将未完成路由标记为“已停止”。

## 6. 验收标准

- 可启动单项采集、多选采集和全选采集。
- `/#settings` 中修改的设置刷新后仍然存在。
- 上轮失败或停止后可立即启动新任务。
- 运行任务可停止，页面不再持续访问目标站点。
- 同一原文不会重复入库，导出内容包含来源和原文网址。
