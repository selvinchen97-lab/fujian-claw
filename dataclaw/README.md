# DataClaw 本地公开信息采集工作台

DataClaw 是一个仅在本机运行的公开网页内容采集与内容入库工作台。它通过本机 Chrome 访问公开栏目页，识别新闻链接、提取正文、去重、保存来源信息，并输出可直接用于前端发布的 HTML。

当前已内置海关总署四条公开资讯路由：媒体聚焦、重要会议、新闻发布会、各关新闻。

## 启动

```bash
npm ci
npm start
```

访问 [http://localhost:4310](http://localhost:4310)。请不要直接打开 `public/index.html`，直接打开文件不会启动本地采集服务。

首次安装、Node 版本和本机 Chrome 的要求见 [安装说明](INSTALL.md)。安装完成后可先执行 `npm run check` 检查代码是否可运行。

## 当前功能

- 采集中心：查看内置路由、设置是否直接推送、单项采集或勾选多项一键采集。
- 轮转采集：默认按“每个栏目各抓一篇，再进入下一轮”的顺序执行，避免连续访问同一栏目。
- 采集设置：可自定义访问间隔、轮次冷却、失败重试、单路由文章上限，并可切换为逐栏目采集。
- 停止任务：运行中的单项或批量采集可立即停止；已保存文章不受影响。
- 内容库：查看、编辑、导出或删除已入库文章。
- 工作日志：按日历和日志记录每个路由的采集结果。
- 正文输出：正文按段落保存，附带来源、采集路由和原文网址；每篇文章生成 HTML 与 JSON 文件。

## 默认采集设置

| 设置 | 默认值 |
| --- | --- |
| 执行方式 | 轮转采集 |
| 列表页间隔 | 20 秒 |
| 正文间隔 | 随机 12–18 秒 |
| 每轮冷却 | 60 秒 |
| 首次限流重试 | 5 分钟 |
| 第二次限流重试 | 20 分钟 |
| 最大重试次数 | 2 次 |
| 每条路由单次上限 | 10 篇 |

设置页面地址：[http://localhost:4310/#settings](http://localhost:4310/#settings)。

## 本地数据与安全边界

- 服务只监听 `127.0.0.1`，不向外暴露本地接口。
- 内容和配置保存在 `data/store.json`。
- 导出内容保存在 `exports/`。
- 采集 Chrome 使用独立、按服务进程隔离的本地配置目录。
- 仅访问 HTTP/HTTPS 的公开页面；不会绕过登录、验证码或网站访问控制。
- 网站临时拒绝访问时，任务会按设置冷却后重试；连续失败会在日志中保留原因。
