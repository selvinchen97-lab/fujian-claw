# 福建公开信息内容工作台

本项目由两个协作部分组成：

- **DataClaw 采集工作台**：通过真实浏览器访问公开网页，预览后采集正文，整理为可发布内容。
- **物流政策与资讯动态静态栏目**：接收 DataClaw 推送的文章，并以福建国际贸易单一窗口物流专区的视觉风格展示。

> 本仓库仅包含程序代码、页面模板和说明文档；浏览器档案、文章内容、导出文件与 API 密钥均保存在本地运行目录，不会提交到 Git。

## 主要能力

- 海关总署“媒体聚焦、重要会议、新闻发布会、各关新闻”四条内置采集路由。
- 使用 Chrome 浏览器会话加载公开网页，支持 HTTP/HTTPS 页面。
- 手动预览资讯列表与正文，再确认入库；也支持单路由采集和一键批量采集。
- 增量去重、访问节流、失败重试、任务停止和工作日志。
- 内容库支持编辑、导出与删除；采集文章保留来源和原始网址。
- 内容库可一键推送到本地 `dist` 中的“物流政策与资讯动态”栏目。
- 采集源开启“直接推送”后，后续成功采集的文章会自动推送到物流栏目。

## 目录结构

```text
福建项目/
├── dataclaw/                    # 采集工作台（Node.js）
│   ├── server.js                # 本地 HTTP 服务与采集任务编排
│   ├── collector.js             # Chrome / Playwright 网页访问与内容识别
│   ├── output.js                # HTML 导出与物流栏目发布器
│   ├── public/                  # 工作台前端
│   ├── data/                    # 本地运行数据（不提交）
│   └── exports/                 # 文章导出文件（不提交）
├── dist/                        # 物流专区静态展示页面
│   └── index.html
└── README.md
```

## 本地运行

### 环境要求

- Node.js 20–26
- npm 10 或更高版本
- Google Chrome（macOS 默认安装路径已适配）

### 启动工作台

```bash
cd dataclaw
npm ci
npm start
```

浏览器访问：<http://localhost:4310/>

检查代码语法：

```bash
npm run check
```

## 使用流程

1. 在“采集中心”选择一条或多条采集路由。
2. 使用“采集”或“一键采集”执行增量采集。
3. 在“内容库”检查文章正文、来源及原始链接。
4. 点击文章右侧的“**一键推送**”，文章会写入 `dist` 的物流政策与资讯动态栏目；再次点击可更新推送。
5. 打开 `dist/index.html`，可查看置顶资讯；点击资讯可进入对应的政策详情页。

“直接推送”开关用于自动发布：开启后，该来源今后新增且成功入库的文章会直接更新物流栏目。

## 数据与安全

- `dataclaw/data/store.json` 保存内容库、采集状态和工作日志。
- `dataclaw/data/browser-standard/collector-profile/` 保存采集专用 Chrome 档案，用于维持正常访问会话。
- `.env` 仅用于本机或服务器保存 API Key 等密钥，已被 Git 忽略。
- 目标站点出现验证码、HTTP 412 或其他访问控制时，程序不会绕过访问控制。
- 公开可访问不等于可无限制转载；对外发布前请核对原始来源的版权、转载和署名要求。

## 物流栏目发布说明

本项目当前推送目标是仓库内的本地静态网站：

- 栏目数据：`dist/data/logistics-news.js`
- 文章详情页：`dist/policy/<文章 ID>.html`

这些文件由运行时自动生成，默认不提交。若需要同步到正式公网网站，还需配置对应网站的发布后台、部署接口或服务器权限。
